# Online Store (os)

Client-facing storefront for purchasing prints, products, and digital downloads. Allows clients to browse a photographer's product catalog, customize orders, and complete purchases.

## Features

- **Product Catalog** - Browse available prints, products, and digital downloads
- **Product Detail** - View product options, pricing, and previews
- **Cart** - Manage selected items before checkout
- **Checkout** - Secure payment processing via Stripe
- **Order Confirmation** - Purchase receipts and order tracking

## Technical Details

- **Prefix**: `os`
- **Styles**: SCSS
- **Components**: Angular standalone components with signals
- **Source**: `src/app/`

## Development

```bash
# Start dev server
ng serve online-store

# Production build
ng build online-store

# Run tests
ng test online-store
```
