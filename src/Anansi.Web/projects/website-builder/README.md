# Website Builder (wb)

Photographer-facing drag-and-drop website editor. Provides a visual editor for photographers to build and customize their portfolio websites without code.

## Features

- **Flex Editor** - Drag-and-drop page layout builder
- **Templates** - Pre-designed website templates and themes
- **Pages** - Multi-page site management and navigation
- **SEO** - Search engine optimization settings and metadata
- **Preview** - Live preview of the published website

## Technical Details

- **Prefix**: `wb`
- **Styles**: SCSS
- **Components**: Angular standalone components with signals
- **Source**: `src/app/`

## Development

```bash
# Start dev server
ng serve website-builder

# Production build
ng build website-builder

# Run tests
ng test website-builder
```
