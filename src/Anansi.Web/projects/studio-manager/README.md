# Studio Manager (sm)

Photographer-facing Studio Manager dashboard application. This is the primary workspace for photographers to manage their business, including CRM, booking, documents, inbox, reports, and settings.

## Features

- **Dashboard** - Overview of business metrics and recent activity
- **CRM / Contacts** - Client management and communication history
- **Booking** - Session scheduling and availability management
- **Documents** - Contracts, invoices, and questionnaires
- **Inbox** - Centralized messaging with clients
- **Reports** - Revenue, booking, and gallery analytics
- **Settings** - Account, branding, pricing, and integration configuration

## Technical Details

- **Prefix**: `sm`
- **Styles**: SCSS
- **Components**: Angular standalone components with signals
- **Source**: `src/app/`

## Development

```bash
# Start dev server
ng serve studio-manager

# Production build
ng build studio-manager

# Run tests
ng test studio-manager
```
