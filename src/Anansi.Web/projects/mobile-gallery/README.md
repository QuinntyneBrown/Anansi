# Mobile Gallery (mg)

Client-facing mobile gallery Progressive Web App (PWA) optimized for photo browsing on mobile devices with add-to-home-screen support.

## Features

- **Mobile Photo Browsing** - Touch-optimized gallery viewing
- **Add to Home Screen** - PWA install prompt for native-like experience
- **Offline Support** - Service worker caching for previously viewed photos
- **Swipe Navigation** - Gesture-based photo browsing in lightbox
- **Share** - Native share integration for individual photos

## Technical Details

- **Prefix**: `mg`
- **Styles**: SCSS
- **Components**: Angular standalone components with signals
- **Source**: `src/app/`

## Development

```bash
# Start dev server
ng serve mobile-gallery

# Production build
ng build mobile-gallery

# Run tests
ng test mobile-gallery
```
