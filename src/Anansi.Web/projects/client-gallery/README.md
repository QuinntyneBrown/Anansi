# Client Gallery (cg)

Client-facing photo gallery viewing experience. Provides the interface clients use to browse, favorite, and download photos from their sessions.

## Features

- **Gallery Homepage** - Landing page with gallery collections
- **Photo Grids** - Responsive image grid layouts
- **Lightbox** - Full-screen photo viewing with navigation
- **Favorites** - Client photo selection and shortlisting
- **Downloads** - Individual and bulk photo downloads

## Technical Details

- **Prefix**: `cg`
- **Styles**: SCSS
- **Components**: Angular standalone components with signals
- **Source**: `src/app/`

## Development

```bash
# Start dev server
ng serve client-gallery

# Production build
ng build client-gallery

# Run tests
ng test client-gallery
```
