# domain-website-builder

Website editor components for building a photographer's portfolio site.

## Components

- **Template Gallery Page** -- Browse and preview website templates
- **Page Manager** -- Add, reorder, and configure site pages
- **SEO Manager** -- Edit meta titles, descriptions, and social sharing settings per page

## Usage

```typescript
import { TemplateGalleryPageComponent } from 'domain-website-builder';
```

## Dev Commands

```bash
ng build domain-website-builder
ng test domain-website-builder
```
