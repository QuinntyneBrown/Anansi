# domain-storefront

Client-facing online store for browsing and purchasing photo products.

## Components

- **Store Browse Page** -- Product grid with filtering and search
- **Cart Page** -- Shopping cart with quantity editing and price summary
- **Checkout Page** -- Shipping, payment, and order confirmation flow

## Usage

```typescript
import { StoreBrowsePageComponent } from 'domain-storefront';
```

## Dev Commands

```bash
ng build domain-storefront
ng test domain-storefront
```
