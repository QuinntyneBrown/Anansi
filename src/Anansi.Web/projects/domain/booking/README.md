# domain-booking

Booking flow and management for scheduling photography sessions.

## Components

- **Session Type Selection** -- Client-facing picker for available session types and packages
- **Booking Form** -- Date/time selection, contact info, and booking confirmation
- **Booking Management Page** -- Photographer's view for managing upcoming and past bookings

## Usage

```typescript
import { BookingFormComponent } from 'domain-booking';
```

## Dev Commands

```bash
ng build domain-booking
ng test domain-booking
```
