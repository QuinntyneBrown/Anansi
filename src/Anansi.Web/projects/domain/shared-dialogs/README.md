# domain-shared-dialogs

Reusable dialog components shared across Anansi applications.

## Components

- **Date Picker** -- Calendar-based date and date-range selection dialog
- **File Upload Modal** -- Drag-and-drop file upload with progress indicators
- **Share Dialog** -- Generate and copy share links with optional password protection

## Usage

```typescript
import { FileUploadModalComponent } from 'domain-shared-dialogs';
```

## Dev Commands

```bash
ng build domain-shared-dialogs
ng test domain-shared-dialogs
```
