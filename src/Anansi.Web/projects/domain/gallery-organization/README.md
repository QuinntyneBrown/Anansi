# domain-gallery-organization

Gallery administration for photographers to organize and deliver client photos.

## Components

- **Collection List Page** -- Grid of all gallery collections with status, cover image, and client info
- **Collection Detail Page** -- Photo management within a collection: upload, arrange, and publish

## Usage

```typescript
import { CollectionListPageComponent } from 'domain-gallery-organization';
```

## Dev Commands

```bash
ng build domain-gallery-organization
ng test domain-gallery-organization
```
