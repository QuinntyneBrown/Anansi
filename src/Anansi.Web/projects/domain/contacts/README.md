# domain-contacts

CRM contact management for the Anansi Studio Manager.

## Components

- **Contact List Page** -- Searchable, filterable table of all client contacts
- **Contact Detail Page** -- Individual contact profile with history, notes, and linked projects

## Usage

```typescript
import { ContactListPageComponent } from 'domain-contacts';
```

## Dev Commands

```bash
ng build domain-contacts
ng test domain-contacts
```
