# domain-store-management

Store administration for photographers to manage products and orders.

## Components

- **Product Catalog Page** -- Create and manage print products, digital downloads, and packages
- **Order Management Page** -- View and fulfill incoming orders with status tracking

## Usage

```typescript
import { ProductCatalogPageComponent } from 'domain-store-management';
```

## Dev Commands

```bash
ng build domain-store-management
ng test domain-store-management
```
