# domain-documents

Document management for contracts and invoices in the Anansi Studio Manager.

## Components

- **Contract List Page** -- Browse, create, and manage client contracts
- **Invoice List Page** -- Browse, create, and manage invoices with payment status tracking

## Usage

```typescript
import { ContractListPageComponent } from 'domain-documents';
```

## Dev Commands

```bash
ng build domain-documents
ng test domain-documents
```
