# domain-settings

Account and notification settings for the Anansi platform.

## Components

- **Account Settings Page** -- Profile info, password change, billing, and plan management
- **Notification Settings Page** -- Email and in-app notification preference toggles

## Usage

```typescript
import { AccountSettingsPageComponent } from 'domain-settings';
```

## Dev Commands

```bash
ng build domain-settings
ng test domain-settings
```
