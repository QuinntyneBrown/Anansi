# domain-gallery-client

Client-facing gallery experience for viewing and selecting photos.

## Components

- **Gallery Home Page** -- Landing page for a shared gallery with cover image and collection overview
- **Favorites Page** -- Client's curated selection of favorited photos
- **Password Entry** -- Access gate for password-protected galleries

## Usage

```typescript
import { GalleryHomePageComponent } from 'domain-gallery-client';
```

## Dev Commands

```bash
ng build domain-gallery-client
ng test domain-gallery-client
```
