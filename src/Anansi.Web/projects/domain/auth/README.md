# domain-auth

Authentication screens for the Anansi platform.

## Components

- **Sign Up** -- New account registration form
- **Sign In** -- Login with email/password
- **Password Recovery** -- Forgot-password and reset flow
- **Plan Selection** -- Tier selection during onboarding

## Usage

```typescript
import { SignInComponent } from 'domain-auth';
```

## Dev Commands

```bash
ng build domain-auth
ng test domain-auth
```
