# Booking Site (bs)

Client-facing booking site for selecting session types, choosing available dates, and completing bookings with a photographer.

## Features

- **Session Types** - Browse available session packages and pricing
- **Date Selection** - Calendar-based availability and scheduling
- **Booking Form** - Client details and session preferences
- **Payment** - Deposit or full payment collection via Stripe
- **Confirmation** - Booking summary and calendar integration

## Technical Details

- **Prefix**: `bs`
- **Styles**: SCSS
- **Components**: Angular standalone components with signals
- **Source**: `src/app/`

## Development

```bash
# Start dev server
ng serve booking-site

# Production build
ng build booking-site

# Run tests
ng test booking-site
```
