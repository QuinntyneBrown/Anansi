# components

Shared UI component library for the Anansi Angular workspace.

## Design System

- **Theme:** Dark (#1A1A1C background, #242426 card surfaces)
- **Accent:** Gold (#C9A962)
- **Typography:** Cormorant Garamond (display), Inter (body/UI)
- **Text:** #F5F5F0

